WHAT I BUILT — Accredian Enterprise Landing Page
==================================================
A Personal Development Narrative by Yash
==================================================


THE ASSIGNMENT
--------------
I was given 48 hours to build a partial clone of enterprise.accredian.com — 
Accredian's enterprise upskilling landing page — using Next.js. The goal was 
to demonstrate frontend engineering maturity, clean architecture, and the 
ability to ship a production-grade product under time pressure.


WHAT I ACTUALLY SHIPPED
-----------------------
Instead of building the minimum 7 sections the assignment asked for, I built 
a complete 13-section enterprise landing page with a full API layer, automated 
tests, scroll animations, and environment-secured configuration. Here is 
everything, broken down honestly.


THE TECH STACK I CHOSE (AND WHY)
--------------------------------
• Next.js 15 with App Router — I chose this over Pages Router because App 
  Router gives me Server Components by default, which means better performance 
  out of the box. The API routes live right next to my pages, keeping the 
  architecture clean.

• TypeScript (Strict Mode) — Every data structure in this project is typed. 
  I defined 15+ interfaces (NavLink, StatItem, DomainCard, FAQItem, 
  LeadPayload, ClientLogo, EdgePillar, etc.) so that my components never 
  receive unexpected data shapes.

• Tailwind CSS v4 — I used the latest version with custom @theme tokens to 
  define a consistent design system. My primary brand color (--universal: 
  #0066FF) flows through every component. I also wrote custom GPU-accelerated 
  CSS keyframes for the infinite logo marquee strip.

• Poppins Font via next/font/google — This matches the actual typography 
  on enterprise.accredian.com. Using next/font means the font is 
  self-hosted and doesn't block rendering.


THE 13 SECTIONS I BUILT
------------------------

1. NAVBAR (Navbar.tsx)
   A sticky header that stays pinned as you scroll. I wrote a custom 
   useScrollSpy hook that uses getBoundingClientRect() to calculate which 
   section is currently in the viewport and highlights the corresponding 
   nav link in real-time. The mobile version has a slide-down drawer with 
   body scroll locking so the background doesn't scroll when the menu is 
   open. Pressing Escape closes it.

2. HERO BANNER (Hero.tsx)
   The first thing visitors see. A bold headline — "Next-Gen Enterprise 
   Upskilling for High-Growth Teams" — with three value proposition 
   bullets and two CTAs. I generated a custom 3D illustration using AI 
   image generation and built a mock enterprise dashboard graphic showing 
   live cohort progress bars.

3. TRACK RECORD / STATS (Stats.tsx)
   Four metric cards showing 10,000+ professionals trained, 200+ 
   corporate partners, 5,000+ projects, and 98% satisfaction. The numbers 
   don't just appear — they animate from 0 using requestAnimationFrame 
   with an ease-out quadratic curve. The animation only triggers when the 
   section scrolls into view (via IntersectionObserver), so there's zero 
   wasted computation on page load.

4. PROVEN PARTNERSHIPS / CLIENT LOGOS (Clients.tsx)
   An infinite marquee strip of 10 official partner logos (Google, 
   Microsoft, Amazon, Deloitte, Accenture, Flipkart, Paytm, Swiggy, 
   Capgemini, Razorpay). The logos display in grayscale and transition to 
   full color on hover. Each logo card is a clickable link to the 
   partner's official website. The marquee runs at 60fps using CSS 
   translate3d for GPU acceleration — no JavaScript animation loop.

5. THE ACCREDIAN EDGE (AccredianEdge.tsx)
   Four pillar cards answering "Why Accredian?" — covering ROI metrics 
   (3.4x average program ROI), faculty quality (top 1% industry 
   practitioners), curriculum customization (100% tailored to your tech 
   stack), and real-time HR analytics dashboards. Each card has a custom 
   SVG icon that inverts colors on hover.

6. DOMAIN EXPERTISE (DomainExpertise.tsx)
   Seven domain cards covering GenAI & LLMs, Product Management, Data 
   Science & AI, Executive Leadership, Business Analytics, Full-Stack 
   Engineering, and Cybersecurity. Each card shows skill competency chips, 
   a "High Demand" badge for popular domains, and an "Enquire" button 
   that smooth-scrolls to the contact form.

7. COURSE SEGMENTATION MATRIX (CourseSegmentation.tsx)
   A 5-tab interactive filtering matrix. Users can browse programs by 
   Type (Certification, Bootcamp, Micro-Learning), Industry Sector 
   (Fintech, Healthtech, Retail), Core Topic, Proficiency Level, or 
   Target Cohort. This helps L&D teams quickly find the right program 
   for their organization.

8. WHO SHOULD JOIN (WhoShouldJoin.tsx)
   Four persona cards identifying the target audience: Engineering Teams, 
   Product Leaders, Mid-Level Managers, and C-Suite Executives. Each card 
   explains the specific organizational outcomes that role would achieve 
   from the training.

9. CAT FRAMEWORK (CATFramework.tsx)
   Accredian's proprietary 3-stage methodology — Competency Mapping, 
   Applied Action Learning, and Transformation Analytics. I visualized 
   this as a stepped timeline showing how training progresses from skill 
   gap audit to measurable business impact.

10. HOW IT WORKS (HowItWorks.tsx)
    A 3-step delivery timeline: Discovery → Co-Creation → Execution. 
    This section removes buyer friction by showing exactly what happens 
    after someone submits an enquiry.

11. FAQ ACCORDION (FAQ.tsx)
    Category-tabbed FAQ section with "About Course", "Delivery & Format", 
    and "Enterprise & Pricing" tabs. Each question expands with a smooth 
    CSS height transition. I built a reusable AccordionItem component 
    with proper accessibility attributes.

12. TESTIMONIALS (Testimonials.tsx)
    Client review cards with 5-star ratings, executive headshot photos 
    (generated via AI), role and company credentials, and review quotes. 
    Includes carousel pagination to browse through testimonials.

13. CONTACT & LEAD CAPTURE (ContactCTA.tsx + LeadForm.tsx)
    The conversion section. Left side shows enterprise contact details 
    (email, phone, address, 2-hour response SLA). Right side is an 
    interactive lead form with 7 fields. The form validates on both 
    client and server side — checking email format, phone length, and 
    required fields. On success, it shows a confirmation message with 
    the generated lead ID.

14. FOOTER (Footer.tsx)
    Full sitemap footer with quick navigation links, program domain 
    links, corporate address, and legal copyright bar.


THE API LAYER
-------------
I built two API routes inside Next.js App Router:

• GET /api/enterprise-data
  Returns the complete data structure for all 13 sections as a JSON 
  response. This simulates how a real backend would serve content to 
  the frontend.

• POST /api/leads
  Receives lead form submissions and validates them server-side:
  - Rejects empty bodies with 400
  - Validates email format with regex
  - Checks phone number minimum length
  - Requires all mandatory fields (name, email, phone, company)
  - Truncates inputs to prevent buffer overflow
  - Returns a unique lead ID on success (201)

SCROLL ANIMATIONS
-----------------
I built a custom animation system with zero external dependencies:

• useInView Hook — A lightweight IntersectionObserver hook that detects 
  when an element enters the viewport. Triggers once and disconnects 
  to avoid unnecessary observer overhead.

• AnimateOnScroll Wrapper — A reusable component with 6 animation 
  variants: fade-up, fade-down, fade-left, fade-right, fade, and zoom. 
  Uses CSS transitions with cubic-bezier easing and willChange cleanup 
  after animation completes to free GPU memory.

• Staggered Card Cascades — Stats cards reveal with 120ms delays 
  between each, Edge pillars at 100ms, and Domain cards at 80ms. This 
  creates a premium "waterfall" effect as users scroll down.


ENVIRONMENT SECURITY
--------------------
All partner company URLs and API endpoints are stored in .env.local, 
not hardcoded. I provided a .env.example template so any developer can 
set up the project without hunting for configuration values.


PERFORMANCE
-----------
• Production build compiles in ~4 seconds with zero errors and warnings
• All images use next/image with proper width, height, sizes, and style 
  attributes — zero console warnings
• Font loaded with display: swap to prevent render blocking
• All section components wrapped with React.memo()
• Scroll handlers throttled with requestAnimationFrame
• IntersectionObserver disconnects after triggering to prevent memory leaks
