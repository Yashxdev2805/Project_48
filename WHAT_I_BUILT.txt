WHAT I BUILT — Accredian Enterprise Landing Page
==================================================
A Comprehensive Development Narrative & Phase Breakdown
Author: Yash
==================================================


THE ASSIGNMENT
--------------
I was tasked with building a production-ready, high-performance partial clone 
of enterprise.accredian.com — Accredian's corporate upskilling landing page 
using Next.js 15, TypeScript, and Tailwind CSS. The goal was to demonstrate 
senior-level frontend architecture, data model precision, full-stack API 
capabilities, and product engineering maturity under a 48-hour deadline.


==================================================
6-PHASE DEVELOPMENT LIFECYCLE
==================================================

PHASE 1: Project Scaffold, Design Tokens & Type Architecture (Hours 0–4)
------------------------------------------------------------------------
• Scaffolded Next.js 15 App Router project with TypeScript and Tailwind CSS v4.
• Configured Poppins font integration via next/font/google.
• Created strict TypeScript interfaces (NavLink, StatItem, DomainCard, FAQItem, 
  LeadPayload, ClientLogo, EdgePillar, etc.) in src/lib/types/index.ts.
• Built centralized enterprise data layer (src/lib/data/enterprise.ts).

PHASE 2: Layout Shell & Hero Experience (Hours 4–10)
---------------------------------------------------
• Built sticky Header Navbar with active section tracking, brand logo, and 
  CTA triggers.
• Designed the Hero Banner featuring high-converting headlines, value 
  bullets, dual CTAs, custom 3D illustration, and live cohort dashboard.
• Added responsive Mobile Drawer navigation with body scroll-locking.

PHASE 3: Social Proof, Partner Marquee & Metrics (Hours 10–18)
--------------------------------------------------------------
• Engineered GPU hardware-accelerated 60 FPS infinite Marquee logo strip 
  (Google, Microsoft, Amazon, Deloitte, Accenture, Flipkart, Paytm, Swiggy, 
  Capgemini, Razorpay) with grayscale-to-color hover and official site links.
• Created Track Record Stats section with RAF-throttled count-up numbers 
  triggered by IntersectionObserver.

PHASE 4: Curriculum, Domain Expertise & Course Matrix (Hours 18–28)
------------------------------------------------------------------
• Developed 7 Domain Specialization cards (GenAI, Product, Data Science, 
  Leadership, BI, Full-Stack, Cyber) with competency chips and badge tags.
• Built 5-tab Course Segmentation Matrix allowing L&D leaders to filter by 
  Program Type, Sector, Topic, Level, and Cohort.
• Created Accredian Edge (4 training pillars) and Audience Persona cards.

PHASE 5: Learning Methodology, Process & FAQ Accordion (Hours 28–36)
-------------------------------------------------------------------
• Visualized the 3-stage CAT Framework (Competency Mapping → Applied Action 
  → Transformation Analytics).
• Created 3-step How It Works delivery timeline.
• Built accessible FAQ Accordion with category tabs ("About Course", 
  "Delivery & Format", "Enterprise & Pricing").
• Added executive Testimonials carousel with star ratings and headshot photos.

PHASE 6: Full-Stack API, Database, Search & Polish (Hours 36–48)
----------------------------------------------------------------
• Created GET /api/enterprise-data and POST /api/leads with server-side 
  validation.
• Built persistent file-based JSON database storage system (src/lib/db.ts).
• Added Global Ctrl+K Search Palette modal indexing all 13 sections.
• Implemented Light/Dark Theme System with localStorage persistence.
• Created 11-test automated API test suite (npm test) — all passing.
• Added Production "Coming Soon" modal triggers for enterprise SSO/PDF options.

PHASE 7: Enterprise SEO, SSR Architecture & Interview Optimization
--------------------------------------------------------------------
• Refactored page.tsx to pure React Server Component (RSC) for 100% pre-rendered 
  HTML payload on initial page load, delivering instant search engine indexability.
• Embedded 4 Schema.org JSON-LD structured data formats (Organization, FAQPage, 
  Course/ItemList, WebSite) for Google Rich Snippet Search Results.
• Implemented full OpenGraph & Twitter Card metadata in layout.tsx.
• Created dynamic sitemap.ts and robots.ts Next.js App Router metadata routes.
• Added accessibility landmarks (Skip to main content, aria attributes, strict h1->h2 heading hierarchy).
• Created comprehensive SEO_AND_INTERVIEW_GUIDE.md technical guide for technical interview evaluation.


==================================================
DIVISION OF LABOR: AGENTS VS. MANUAL WORK
==================================================

AI AGENTS CONTRIBUTIONS
-----------------------
1. Site Analysis & Architecture: AI analyzed the live enterprise.accredian.com 
   JS/CSS bundles to map section structures, color tokens, and layout schemas.
2. Data Structure Generation: AI assisted in extracting structured content into 
   typed TypeScript interfaces inside lib/data/enterprise.ts.
3. CSS Animation Keyframes: AI generated the initial translate3d keyframe logic 
   for the infinite 60 FPS marquee animation.
4. Test Suite Scaffold: AI generated the initial 11-test automated API test suite 
   scaffold in src/__tests__/api.test.ts.

MANUAL & HAND-CRAFTED ENGINEERING (YASH)
-----------------------------------------
1. Pixel-Accurate ScrollSpy Engine: Hand-coded the getBoundingClientRect() top 
   position tracking in useScrollSpy.ts to eliminate section boundary bugs.
2. Custom UX Controls: Built the mobile drawer body scroll locking, Escape key 
   handlers, and smooth scroll anchor transitions.
3. Persistent Database System: Architected src/lib/db.ts with in-memory 
   caching and disk persistence to save lead inquiries reliably.
4. Tailwind v4 Dark Mode Variant Configuration: Configured @custom-variant 
   dark (&:where(.dark, .dark *)) in globals.css to fix dark mode switching.
5. Image Performance Tuning: Audited and configured explicit style rules 
   (style={{ width: "auto", height: "auto" }}) across Next.js Image components, 
   achieving ZERO console warnings.
6. Environment & Git Security: Configured .env.local / .env.example split, 
   wrote root and project .gitignore rules, and managed repository commits.
7. Vercel Deployment & Build Optimization: Verified production builds, 
   optimizing compilation time down to ~3.0s.
